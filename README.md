# Gesture-Based Virtual Air Interface System

## Overview
This project aims to develop a real-time gesture-based human-computer interaction system using MediaPipe hand tracking.

## Current Progress
- Researching gesture mapping techniques
- Testing MediaPipe landmark detection
- Experimenting with finger state logic
- Refactoring gesture classifier module
- Designing modular architecture

## Planned Features
- Air canvas drawing
- Cursor control
- App switching gesture
- Screenshot trigger

## Tech Stack
Python, OpenCV, MediaPipe, PyAutoGUI
